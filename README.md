# OSHH Styler

Оформление и настройка для [Omarchy](https://omarchy.org) — TUI-приложение на
[Textual](https://textual.textualize.io/): темы, обои (включая видеообои),
экран блокировки и входа, окна и анимации, шрифты и курсор, панель, параметры
Hyprland, а также звук, сеть, экраны и питание.

Это **отдельное приложение**: оно ставит свою команду `oshh-styler` и свой
пункт в меню программ («OSHH Styler») и **не заменяет** встроенные пункты меню
Omarchy (Style / Setup) и их скрипты. Можно держать оба варианта одновременно.

## Установка (Arch)

Из тега релиза через makepkg:

```bash
git clone https://github.com/Fanikalin/oshh-styler
cd oshh-styler/packaging
makepkg -si
```

Потом: пункт «OSHH Styler» в меню программ или команда `oshh-styler`.
Режим настройки системы: `oshh-styler --setup`.

Зависимости: `omarchy` (AUR), `python-textual`, `python-pillow`, `ffmpeg`,
`zenity`, `xdg-terminal-exec` (или kitty / alacritty / foot).

## Разделы

Оформление: Тема, Обои, Экран блокировки, Экран входа, Окна, Анимации, Шрифты
и курсор, Панель и заставка, Столы и раскладка, Все параметры Hyprland, Файлы
конфигурации.

Настройка (`--setup`): Звук, Сеть, Экраны, Питание, Мышь и клавиатура, Окна и
фокус, Программы по умолчанию, Конфигурация.

У каждого раздела есть предпросмотр: макет экрана, раскадровка анимации с
графиком кривой, поле для проверки ввода, текущее состояние системы или
содержимое файла. «Все параметры Hyprland» строится из `hyprctl descriptions
-j`, поэтому новые параметры Hyprland появляются сами.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `↑` `↓` | Строка |
| `←` `→` | Изменить значение, с `Shift` шаг ×10 |
| Клик в списке тем и обоев, по пресету, по строке с действием | Выделить и показать предпросмотр |
| `Enter` | Применить, выбрать, ввести, запустить. В боковой панели — перейти на страницу |
| `r` | Вернуть значение из конфига |
| `e` | Открыть `hyprland.lua` во внешнем редакторе |
| `Esc` | К разделам |
| `q` | Выход |

## Что куда пишется

| Файл | Содержимое |
| --- | --- |
| `~/.config/hypr/hyprland.lua` | Конфиг пользователя. Приложение только один раз добавляет подключение слоя, копия — `hyprland.lua.before-oshh-style` |
| `~/.config/hypr/oshh-style.lua` | Слой поверх конфига: только изменённое. Удалите файл, и останется чистый конфиг |
| `~/.config/oshh/style.json` | Значения, из которых собирается слой |
| `~/.config/oshh/wallpaper.conf` | Масштаб, пауза и скорость видеообоев |
| `~/.local/state/oshh/wallpaper/<тема>` | Обои, выбранные для темы |
| `~/.config/omarchy/backgrounds/<тема>/` | Копии своих обоев и клипы из каталога |
| `~/.config/hypr/hyprlock.conf`, `hypridle.conf` | Правятся построчно, комментарии остаются. Часы и логотип — блоки с метками `# oshh-style` |
| `~/.config/oshh/lock-logo/` | Свои логотипы экрана блокировки, копии выбранных файлов |
| `/var/lib/oshh/greeter/` | Настройки и картинка экрана входа (нужны права группы `wheel`) |

Свои обои и логотип выбираются в окне выбора файлов (`zenity`). Приложение
копирует файл к себе, исходник можно удалить. Новые обои только выделяются,
ставит их `Enter`.

## Каталог видеообоев

`catalog.json`: 46 клипов с Pexels, у каждой из 28 тем есть хотя бы один. Они
показаны в общем списке обоев с кружком справа, а пункт «Другие обои»
раскрывает всё остальное: обои других тем и клипы каталога, ближайшие к цветам
текущей темы сверху. Лицензия Pexels запрещает распространять файлы отдельно,
поэтому в пакете только ссылки, клип скачивается по запросу пользователя.
